## 📥 Download

Scarica l'ultima versione eseguibile dalla [pagina delle Release](https://github.com/Yagor-Studio/sprite-animation-studio).

## 🚀 Avvio rapido

### Per utenti (eseguibile)
1. Scarica `SpriteStudio.exe` dalle Release.
2. Esegui il file.

### Per sviluppatori (codice sorgente)
```bash
git clone https://github.com/Yagor-Studio/sprite-animation-studio.git
cd sprite-animation-studio
pip install -r requirements.txt
python -m sprite_studio.main


```
